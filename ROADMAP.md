# Endrise Roadmap

The long-term vision: a full End update. The End today is one fight, one loot run, and a lot of empty yellow islands. Endrise grows it in **tides**, each one small enough to ship and play.

Items below marked *proposal* are open for discussion in issues; nothing here is promised in order.

## Tide 1 — Enderium (shipped, v0.1.0)

- [x] Enderium ore in end stone, all End biomes
- [x] Raw enderium, smelting/blasting to ingots
- [x] Diamond-tier mining, Fortune/Silk Touch correct

## Tide 2 — A reason to dig (next)

- [ ] Enderium storage block (9 ingots, build with it)
- [ ] Enderium tools *(proposal: what makes them not-just-another-tier? Current thinking: void-touched — items that fall into the void return to you)*
- [ ] Enderium armor *(proposal: set bonus themed around ender mobility or void safety)*

## Tide 3 — The islands themselves

- [ ] Surface flora beyond chorus *(proposal: something that grows on or near enderium veins)*
- [ ] Deco block family: polished/bricked end stone variants, enderium-accented
- [ ] Ambient touches: sounds, particles in the outer islands

## Tide 4 — Structures and inhabitants

- [ ] A small structure worth detouring for
- [ ] A neutral mob *(big swing, needs design first)*

## Good first contributions

- Enderium storage block (model + recipe + loot, follows the ore's file layout exactly)
- Recipe advancement triggers (vanilla ores unlock recipe book entries when you pick up the raw item)
- Texture polish passes (see art guidelines in CONTRIBUTING.md)
- Playtest reports: is the ore too rich? too shallow? File an issue with your world seed.
